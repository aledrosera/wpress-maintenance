# Phase: media

## Objective
Only the media the site uses, each one optimized.

## Determine
- Usage from real visits of every inventory URL at desktop, tablet and mobile widths, scrolling to the bottom: files requested, plus every upload reference in the DOM (sources, responsive sets, posters, data attributes, inline styles), in inline scripts and in all CSS rules of every breakpoint. Map responsive and modern-format variants back to their attachment.
- Files generated by builders from an attachment, and the attachment each one depends on.
- References built dynamically by custom code: search code and database for exact media file names.
- Cross-check: every media file the live site uses exists locally.
- Files that belong to no attachment, and copies kept by optimization tools.
- Weight: totals by type, largest files, video codec, resolution, bitrate, duration and audio, and how each video is embedded (preload, autoplay, controls).

## Decide
- Delete unused attachments through WordPress, then orphan files.
- For attachments in use, remove the generated sizes nothing references and update their metadata so WordPress never outputs a missing file; keep the main file.
- Recompress images keeping names and paths; keep modern-format variants only where smaller; strip metadata.
- Videos: a codec and container that play in every major browser and device, a bitrate suited to resolution and use, fast start, no audio track for background videos; keep the result only when materially smaller.
- Stop generating sizes the site never uses, with a setting that travels with the site.
- Unused media are deleted whatever their upload date; recent ones are listed in the report.
- Processing tools are installed temporarily inside a container and removed at the end.

## Risks to check
- Builder-generated files depend on the original attachment: deleting it breaks their regeneration.
- Media used only on interaction (lightboxes, later slides) are in the DOM: DOM references count as usage.
- A video with automatic full preload is downloaded entirely when the page opens.
- Name prefixes collide: match media names exactly.

## Exit criteria
A real visit shows zero missing media on every URL and width; every media file used by the live site exists locally; weight before and after is measured.

## Report
Attachments, files and upload size before/after; what was deleted; compression choices; video changes.
